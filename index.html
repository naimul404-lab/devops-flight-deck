Branching

02

03

Docker

Git workflow

Version control
  • Create a feature branch from main
  • Commit focused changes with clear messages
  • Open a pull request for review
  • Resolve conflicts before merge
  • Deploy the validated branch

Docker basics

Containers
  • Dockerfile defines the app environment
  • docker build creates an image
  • docker run starts a container
  • Use docker-compose for multi-service setups

CI/CD pipeline

Automation
1. Code pushed
2. CI checks run
3. Tests validate build
4. Deploy to target
